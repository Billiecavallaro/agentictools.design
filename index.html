    AI agents for designers and PMs, answered

    What is agentictools.design?

    agentictools.design is a free guide to which AI agents product designers and product managers should use for which job. It has 14 use cases, each with the recommended setup: which agents to use, in what order, and why. It also keeps a directory of 27 AI agents across 6 categories, updated daily, where each listing explains what the tool does in about 30 seconds, who it is for, what it is best at and what it costs, checked against the product's own website, plus 6 workflows that chain them together.

    Which AI agents should designers and PMs use for what?

    It depends on the job. These are the setups we recommend, with the agents in the order you'd use them:

    • Synthesize user interviews into themes: Dovetail → Claude → Linear Agent
    • Run user interviews at scale with an AI moderator: Outset → Dovetail
    • Test a prototype with real users: Figma Make → Maze
    • Turn customer feedback into a spec: Samepage Bets → ChatPRD → Linear Agent
    • Write a PRD from meeting notes: ChatPRD → Notion Agent
    • Run a competitive analysis: ChatGPT agent → Claude → Notion Agent
    • Turn a PRD into a clickable prototype: ChatPRD → v0 → Maze
    • Generate UI that uses your own design system: Figma agent → Wonder → Claude Code
    • Turn a whiteboard sketch into a prototype: Stitch → Figma Make
    • Prototype a new feature inside your real product: Wonder → Codex
    • Turn a Figma design into production code: Wonder → Claude Code → GitHub Copilot
    • Get design QA fixes shipped: Linear Agent → Cursor → GitHub Copilot
    • Build a working app without writing code: ChatPRD → Lovable
    • Automate status updates and stakeholder reports: Notion Agent → Claude

    See every use case with the reasons.

    What is an AI agent workflow for design and product work?

    A workflow is a short, repeatable chain of AI tools that ends in something you can ship or share. For example, Library-true screen to shipped code uses Figma agent, Wonder, Claude Code:

    • Draft the screen with the Figma agent using your own components
    • Bring it into Wonder and explore variations on the canvas
    • Have Claude Code build the chosen version in its own worktree

    The result: A reviewed preview built from your design system, ready to merge. The directory has 6 workflows.
