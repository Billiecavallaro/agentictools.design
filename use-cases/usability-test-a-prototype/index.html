Test a prototype with real users

Build the prototype in Figma Make, then run an unmoderated test in Maze, which recruits people from its own panel and writes the report. You get real reactions without scheduling a single call.

Best for: Designers and PMs who want evidence before engineering starts.

Watch out: Write tasks as goals, like find a plan for a team of five, not as instructions like click Pricing. Otherwise you're testing your copy, not your design.

  1. Figma MakeMakes the prototype
  2. MazeRecruits, tests and reports

How it works

  1. Figma Make: Turns your frames into a working prototype people can click through. See site
  2. Maze: Recruits participants from a 6M+ panel, runs the test unmoderated and generates the report. Free trial; plans, see site

Or swap in

v0if the prototype needs to be a deployed web app, not a click-throughOutsetif you want conversations, not task completion. It runs AI-moderated interviews at scale

Workflow: Idea to tested prototype in a day

  1. Draft the PRD from meeting notes in ChatPRD
  2. Open the spec in v0 to build a clickable app
  3. Run an unmoderated prototype test with Maze participants

Result: A working prototype with real user feedback attached. Open this workflow
