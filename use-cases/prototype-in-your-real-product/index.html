Prototype a new feature inside your real product

Use Wonder. It's a design canvas on your actual product where the design stays as code, and it runs a coding agent like Codex to build what you design. If you just want a quick build from a GitHub repo, Bolt can start from the repo and keep your design system.

Best for: Product teams who are done with throwaway prototypes.

Watch out: Prototyping on real code means real constraints show up early. That's the point, so don't fight it.

  1. WonderDesigns on the real product
  2. CodexBuilds the change in the cloud

How it works

  1. Wonder: Design on the real product, with the design kept as code instead of a separate mockup. See site
  2. Codex: Builds the change in the cloud, even with your laptop closed, and checks its work with browser tools. Included with ChatGPT Plus, Pro and Business

Or swap in

Boltif you want a quick build that starts from your GitHub repo or Figma file and keeps your design systemCursorif an engineer is pairing with you. Cursor's cloud agents build, test and demo features in parallel

Workflow: Library-true screen to shipped code

  1. Draft the screen with the Figma agent using your own components
  2. Bring it into Wonder and explore variations on the canvas
  3. Have Claude Code build the chosen version in its own worktree

Result: A reviewed preview built from your design system, ready to merge. Open this workflow
