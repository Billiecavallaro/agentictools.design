Generate UI that uses your own design system

Start in Figma with the Figma agent, which builds screens from your real library components, tokens and variables. When you want to see it as code, move into Wonder, where the design stays as code and a coding agent builds the version you pick.

Best for: Product designers and design system teams tired of generic AI screens.

Watch out: AI is only as on-brand as your library. If your components and tokens are messy in Figma, the agent will copy the mess faithfully.

  1. Figma agentDrafts screens from your components
  2. WonderExplores variations as code
  3. Claude CodeBuilds the one you pick

How it works

  1. Figma agent: Drafts and refines screens from your own components, tokens and variables instead of placeholder UI. It comes with paid Figma plans. Included on paid Figma plans
  2. Wonder: Explore variations on a canvas where the design is kept as code, so what you pick is what gets built. See site
  3. Claude Code: Builds the chosen version. Wonder runs it in its own git worktree, and you get the change back to review. Included with paid Claude plans; Team $20/seat/mo billed annually
